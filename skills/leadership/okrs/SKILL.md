# OKRs

These concepts help you set and run goals. They are drawn from John Doerr's *Measure What Matters*, which builds on Andy Grove's management practice at Intel. An **objective** is *what* is to be achieved: significant, concrete, action-oriented, and ideally inspiring. **Key results** are *how* you know you are getting there: specific, time-bound, and verifiable. Doerr's formula: "I will ___ as measured by ___." OKRs give four "superpowers": **focus**, **alignment**, **tracking**, and **stretch**. They work best paired with **CFRs** (conversations, feedback, recognition).

OKRs measure progress; they are not the strategy. Set them after the strategy is clear, so each objective follows from a guiding policy and acts as a proximate objective. See the `strategy-kernel` skill.
