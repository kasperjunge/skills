# Core values

Core values are the essential and enduring tenets of an organization: a small set of guiding principles that need no external justification. They are part of the **core ideology**, together with the [core purpose](core-purpose.md).

## Principles

- **Few.** Typically three to five. More than that usually means practices, strategies, or cultural norms are being confused with values.
- **Discovered, not set.** Values describe what people already hold to be true. You can't install them; you can only articulate them.
- **Intrinsic.** They matter to the people inside the organization for their own sake, not because they pay off or are fashionable.
- **Enduring.** They should hold for 100 years, even as the world and the business change.
- **No universally right set.** What matters is authenticity and consistency, not which values are chosen.

## Tests for a core value

- If you were starting a new organization, would you build it around this value regardless of the industry?
- Would you keep it even if it became a competitive disadvantage?
- Would you want people to keep holding it 100 years from now?
- If circumstances changed and penalized you for holding it, would you still keep it?

If the answer is no, it's not a core value; it may be a practice or a strategy.

## Finding them: the Mars group

Collins and Porras suggest asking: if you had to recreate the very best attributes of the organization on another planet with only five to seven people, whom would you send? These people tend to embody the core values and have high credibility. Ask them to articulate what they hold to be true.

## Core values vs. non-core

| Core value | Not a core value |
|---|---|
| Integrity in everything we do. | Customer-first service policies (a practice). |
| Relentless improvement. | Being the low-cost provider (a strategy). |
| Respect for the individual. | Open-plan offices and casual dress (a norm). |

## Failure modes

- **Aspirational values.** Values that describe who you wish you were, not who you are. Aspirations belong in the envisioned future or strategy.
- **Generic virtue lists.** "Integrity, excellence, innovation, teamwork" adopted because other companies have them.
- **Too many.** A long list that nobody remembers or acts on.
- **Unenforced values.** People who violate the values face no consequences, so the values are ignored.
