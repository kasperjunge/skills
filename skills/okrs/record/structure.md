# OKR record

A durable record of OKRs across cycles.

```
okrs/
├── README.md               # how we run OKRs, links to years
└── <yyyy>/
    ├── README.md           # annual OKRs
    └── q<n>.md             # quarterly OKRs, optional
```

Objectives and key results get stable IDs (`O1`, `KR1.2`). A quarterly objective links to the annual key result it serves, if any.

Templates are a starting point: add, drop, or rename sections to fit what you learn.

- [Year](templates/year.md)
- [Quarter](templates/quarter.md)

After creating a record, offer to add it to the [Strategic Context](templates/strategic-context.md).
